# GYM ARC - Bug - Quarter pipe sides looked like stairs

Back to [[00 GYM ARC Home|GYM ARC Home]] · [[GYM ARC - Bugs index|All bugs]]

- **What happened:** The skate park quarter pipes had stepped sides like stairs.
- **Cause:** The side walls were stacked boxes.
- **Fix:** Each side is a solid cheek whose top follows the curve.
