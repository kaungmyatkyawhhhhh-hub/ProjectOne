# GYM ARC - Credits

Code and tools made by other people that the game uses.

## TopbarPlus (by ForeverHD)
- What: makes the buttons on Roblox's own top bar (our coins, height, level, Daily, Quests and the gear). They look and line up exactly like Roblox's buttons, and buttons that don't fit go into a small overflow menu.
- Version: v3.4.0 (the newest on 14 Oct 2026).
- Where it came from: the official Creator Store model by ForeverHD, asset 92368439343389 (the old Nanoblox listing points to it). Checked: only code modules (no scripts that run on their own); the example READ_ME script and the thumbnail parts were deleted.
- Where it lives: `ReplicatedStorage.Packages.Icon` (not edited, so it can be updated later). Backup in GitHub under `src/ReplicatedStorage/Packages/Icon`.
- Links: DevForum thread "TopbarPlus" (devforum.roblox.com/t/topbarplus/1017485), docs at 1foreverhd.github.io/TopbarPlus.
- Used in: [[GYM ARC - UI System]].
