# GYM ARC - Run Cards: what to add in future updates (5 Nov)

Owner: "for future updates what should we do for cards". Builds on [[2026-11-05 GYM ARC Prompt - Run Cards v2 FULL (talents, unique, every 2 alters)]].
Pattern from Deepwoken (talents grow every update; Oaths = class-defining talent sets) and roguelite deckbuilders (new cards each update, synergies, a collection to complete).

1. **2-3 new talents every update, themed on that update** (Plates update -> plate talents, Gem update -> gem talents). Cheapest way to make every run feel new. Each needs an icon in the same style + a prerequisite web.
2. **Card Book (collection)**: every card you've ever found, greyed until found, rarity counts, small rewards for completing a rarity (title, badge, card back). Gives long-term goals.
3. **Event-only talents**: drop only during a live event; can be kept as legacy forever (the "mutation" chase, without a new system).
4. **Paths (big update, Deepwoken Oath-style)**: at the first card of a run choose Bodybuilder / Powerlifter / Strongman; each unlocks 3-4 path-only talents. Gives runs a direction. Do when there are ~35+ cards.
5. **Mythic tier (1-3 cards)**: ~0.5%, its own Sol's-RNG-style reveal cutscene + server message. Only after the talent pool is big.
6. **Cosmetic card styles**: foil/holo frames and card backs (earned from the Card Book; could be sold as cosmetics later - never cards, picks or rerolls for Robux: paid random rules).
Order: 1 every update · 2 next · 3 with the next event · 4 + 5 later. Never: selling cards/rerolls, removing cards players own, stacking boosts back in.
