
Put downloaded car models (.glb / .fbx / .obj, under 100 MB) here and push them.
Claude converts them for Studio (File > Import 3D) and removes the originals once the cars are in the game.

`new_cars/` holds the converted cars waiting for you to bring in with Import 3D. Import every file in it,
save your place as `CityLegendsCars.rbxl` and push. Once they are in the game, Claude empties the folder.
