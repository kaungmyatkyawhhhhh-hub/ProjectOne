## How the owner trains the brain
1. **Drop it in the inbox:** write one line in [[Brain/Training inbox]] ("When X, do Y, because Z" or "new method: ..."). Any length, any language.
2. **Or say it in chat:** "teach you this", "make it a method", "remember this rule". Claude files it the same day.
3. **Claude turns it into the right layer:** a method (how to think), a lesson (a rule from a mistake), a gate item (a check), or knowledge (facts). The night shift empties the inbox every night.
4. **Every correction counts:** when the owner says something is bad, Claude writes the cause + the rule in Lessons, so the same mistake never comes back in any game.
5. **Methods get better:** after each use, Claude adds what it learned to the method note ("Used on: ... / Learned: ...").

## Rules for Claude
- Before planning any game work: check this note's Methods table. If a method fits, follow it (and say which one in one line).
- After any owner correction: add a Lessons entry (what felt bad / cause / fix / rule).
- New repeatable way of thinking from the owner → a new method note from [[Brain/Method template]], add it to the table, and offer to make it a skill.
- Keep this index short: details live in the method notes.
- **Skills live in the vault too:** every new or updated skill is copied to [[Brain/Skills/00 Skills index|Brain/Skills]] (`<name>/SKILL.md`) in the same turn, and the index is updated (owner, 13 Nov 2026).
