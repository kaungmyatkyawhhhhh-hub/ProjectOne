# Robux revenue numbers (researched 26 Nov 2026)

Check the official pages again before relying on these: Roblox changes them.

| Number | Value | Source |
|---|---|---|
| DevEx standard rate | $0.0038 per Earned Robux ($114 per 30,000) | Roblox Creator Docs, Developer Exchange: https://create.roblox.com/docs/production/monetization/developer-exchange |
| DevEx higher rate | $0.0054 per Earned Robux from US players verified 18+ buying passes, dev products, subscriptions and private servers (from 8 Jun 2026) | same page; https://en.help.roblox.com/hc/en-us/articles/13061189551124 |
| Legacy rate | $0.0035 for Robux earned before 5 Sep 2025 | https://www.lilachbullock.com/robux-to-usd/ |
| DevEx minimum | 30,000 Earned Robux | Roblox DevEx page |
| Creator share | 70% of passes and dev products (30% marketplace fee) | https://www.studioinsights.net/numbers |
| Premium Payouts | Paid by Premium players' engagement time, no marketplace fee. Per-minute rate is not public: read yours from the Creator Dashboard | https://rolearn.dev/insights/roblox-developer-revenue-share-2026/ |
| Payer conversion | 1-3% typical, top games ~8%; under 1% = a broken buy flow or prices | https://zehn-studio26.com/glossary/conversion-rate/ (third party) |
| One incremental game | ~0.5% payers, ARPPU ~95 R$ | creator post, https://x.com/EvanZir/article/2074281929575174603 |
| ARPDAU | = payer conversion x ARPPU (Roblox's own definition) | https://create.roblox.com/docs/production/analytics/monetization |
| Genre benchmarks | Creator Dashboard "similar experiences" band, 50th-90th percentile, for payer conversion, ARPPU, ARPDAU | https://devforum.roblox.com/t/analytics-similar-experience-benchmarks-broader-access/2210285 |
| Price tests | Roblox Managed Pricing / price tests in the Creator Dashboard | https://devforum.roblox.com/t/managed-pricing-one-system-for-better-pricing-and-earnings-growth/4684738 |
| Monetization playbook | Roblox's official foundations | https://devforum.roblox.com/t/monetization-foundations-playbook/2569495 |

Not found anywhere public: controlled starter-pack conversion studies, real price-elasticity data. Mobile ARPDAU tables (GameAnalytics etc.) do not transfer to Roblox.
