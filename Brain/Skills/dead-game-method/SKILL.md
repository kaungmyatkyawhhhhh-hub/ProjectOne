# The Dead Game Method

The owner's method (9 Nov 2026): thousands of multiplayer games were shut down, but many had great ideas and passionate communities. Use them as a research library. Library note: vault `Roblox Playbook\Research notes\2026-11-09 Research - Dead game method (shut-down multiplayer games as an idea library)`. Always read it first and ADD to it, never start a new one.

## 1. Research (web, with sources)
For each dead game (aim 8-12 new ones per pass, mix kids' worlds, co-op, PvP, MMOs, mobile):
- **Why players loved it:** the exact mechanic and feeling (not just "it was fun").
- **Why it died:** business model, platform, skill barrier, team-dependence, slow updates, owner/licence decision, costs.
- **What players still miss:** fan servers, revival projects, anniversary events, Reddit threads, "I miss" articles.

## 2. Find the patterns
- What to copy (shared places, scarce dated events, homes to visit, things to care for and collect, readable co-op combos, funny chaos, asymmetric roles...).
- What Roblox already fixes (free, phones, servers, moderation) and what it does NOT (skill floor, needing a full team, empty queues, slow updates, cosmetic-only money). Every concept must solve the second list: bots/solo play, a 60-second onboarding, weekly updates, Roblox-style progression.

## 3. Reinvent as ORIGINAL Roblox concepts
- Borrow the mechanic and the feeling, never names, characters, art or story.
- Per concept: hook in one line, core loop, the round or session shape, what it borrows from which game, how it avoids that game's death, money (fixed prices, max 449 R$, no paid random items), and a 1-week prototype scope.
- Score for the owner's goals (kids, phones, 1K CCU, small team strong at incrementals) and pick one.

## 4. Steal for the current game
List 3-5 small things the live game can take now, check in Studio what already exists, and write one Claude Code prompt for only the missing parts (don't playtest or publish).

## 5. Save
Update the library note (table + patterns + concepts + sources) and link any prompt from it.
