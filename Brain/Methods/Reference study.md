# Reference study

**Owner's words:** "this is so bad. watch these references" (7 Nov, the first TikTok)
**Use when:** before making anything the owner judges by eye: videos, UI, icons, thumbnails, maps.

## Steps
1. Get 3-5 references the owner likes (or find the top 10 in the genre).
2. Study them for real (frames, timings, sizes, colours, pacing), not from memory.
3. Write what makes them good as rules (numbers where possible).
4. Make ours, then compare side by side before showing the owner.
