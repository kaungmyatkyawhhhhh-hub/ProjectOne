# Dead game method

**Owner's words:** "research discontinued multiplayer games, that had passionate communities, find out why players liked those games fun and why people stop playing and which mechanics player still miss and then take those mechanics and then reinvent them as original roblox game concepts, using forgotten games as an research library" (9 Nov)
**Use when:** new game ideas, new features, "how do we make this more fun / social".
**Skill:** dead-game-method

## Steps
1. Read the library first: [[Roblox Playbook/Research notes/2026-11-09 Research - Dead game method (shut-down multiplayer games as an idea library)]]. Add to it; never start a new one.
2. Research 8-12 more dead games (with sources): why loved (the exact mechanic), why died, what fans still miss.
3. Patterns: what to copy; what Roblox already fixes (free, phones, servers, moderation); what it doesn't (skill floor, needing a full team, empty queues, slow updates) → every concept solves those.
4. Reinvent as ORIGINAL concepts (mechanic + feeling, never names/art/story); score for kids, phones, 1K CCU, small team.
5. "Steal now": 3-5 small things for the live game; check Studio for what exists; one prompt for the missing parts.

## Used on
- 2026-11-09: 12 games → MONSTER GROW pick; Galaxy got the monthly party, island stars, the Great Star, the LUMI pet → [[Celestial Incremental/2026-11-09 Galaxy Incremental - Prompt - Dead game method features (party, island stars, Great Star, LUMI pet)]]

## Learned
- Size shared goals to the real player count (the Great Star started at 500 for a 25-DAU game).
- Built 9 Nov (Claude Code): a shared, galaxy-wide counter must count events at the source (the server's Supernova), not attribute changes (it counted a loaded save as new points). Put new social goals on existing landmarks / boards (the Core, the leaderboard wall's 2nd page) instead of new boards: no map pass needed.
