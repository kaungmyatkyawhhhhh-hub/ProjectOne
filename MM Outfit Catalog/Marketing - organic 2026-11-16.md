## 5. Brief + tracking (after a price is agreed)
- **Show:** the one-tap try-on in the first 2 s, then the Random roll.
- **Tracking:** MM has no promo codes; its "Codes" page looks up outfit IDs. So each creator features **their own outfit ID** ("type ID 05 in Codes").
  - To count it, the game needs one small addition: log each Codes lookup by ID (AnalyticsService custom event). **Not built**; build it when a creator test is booked.
- **Price check:** cost per 1K views = price ÷ (median views ÷ 1000). It beats ads only below about $0.07 per 1K views at a 1% view-to-play rate, which is a low bar. Show the owner the maths.
- **Required:** the paid-partnership label on; no "free Robux"; no fake "limited time".
