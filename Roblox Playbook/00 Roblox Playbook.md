# Roblox Playbook

How to make Roblox games better in every way, researched 28 Oct 2026 for GYM ARC, SPEED ARC and future games. Use it before planning any update, launch or new game.

## The 8 biggest things right now
1. **Home algorithm (since 15 Jun 2026)** judges a game over **28 days**: play-through rate, players leaving in the first 60 s / 3 min, days played and playtime per player (day 1, days 2-7, days 8-28), playing with friends, spending days. Clickbait thumbnails now hurt.
2. **Kids and Select (global since 16 Jun 2026):** to reach players under 16 you need: creator age-checked + ID-verified + 2-Step Verification, the full maturity questionnaire (aim Minimal/Mild), a refundable fee (or Premium 2 months), and passing a trial with 16+ players. Unrated games can't be played.
3. **First 3 minutes on a cheap phone** decide everything: fast load, first action in seconds, show don't tell, hints only when stuck.
4. **Retention hooks that reach kids:** offline progress, daily streaks, quests, friend boost, invite rewards for both players, a fixed weekly event (e.g. Saturday). Notifications and social/Discord links only reach 13+/16+.
5. **Money:** you keep 70% of passes/products; DevEx $0.0038 per Robux (30,000 minimum); Creator Rewards pay for 10+ minute sessions. Read prices from Roblox (Managed Pricing), never type them in.
6. **Rules:** exact % odds before any paid egg/roll, no fake sales or resetting timers, filter all player-typed text, no links inside games, no real brands/people.
7. **Performance targets:** test on a real low-end phone, ~1,000 draw calls and 1M triangles max, textures 512 px or less, no partly transparent parts, streaming on. Data with ProfileStore; validate every remote on the server.
8. **Trends:** big hits come from a clear concept + weekly updates + creators/TikTok; late clones rarely win. Treat a trend as "theme + one twist", build small and fast.
