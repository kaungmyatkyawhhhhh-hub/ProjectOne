## Read
- The +1/evolution wave is the clearest fit: 5 hits in one month, simple loop, kids' audience, the owner already clicks these (+1 Venom icon), and it needs progression design (our strength).
- SPEED ARC was already redesigned on 28 Oct as "+1 SPEED every step" (paused 29 Oct) = exactly this wave. Running/speed isn't taken yet in the list.
- Ragdoll = saturating fast; horror = needs story/atmosphere craft; steal-a-X = huge but crowded and needs PvP/base systems.

## Recommendation
1. **SPEED ARC as "+1 Speed"** (revive it; launch window matters, the +1 wave won't last forever): +1 speed per step, smash walls, evolve your runner, a boss/race every few minutes, pets/trainers later. Build it light, ship fast (2-3 weeks), group P&L Studios.
2. Alternative: a "throw for distance + collect" game (Throw Food For Animals pattern).
Order vs Galaxy: Galaxy launch 5 Dec stays first unless the owner decides to run both (Claude Code builds in parallel).

## Owner (6 Nov): "+1 is too much this month already. depth incremental-like game is good"
Depth Incremental (Core Loop, solo dev, created 8 Oct 2026): 23.4K CCU, 6.2M visits, **124K favourites** (2% of visits - very high), 29.7K up / 1.2K down (96%), 4 updates in a month (UPD4, updated 5 Nov). "Heavily inspired by Zenith and Tower Incremental".
Loop: buy steps to descend into the pit -> each LAYER has something new + dangerous -> dig Fossils, hunt rare Shinies (luck) -> many upgrade trees -> a BOSS guards each layer -> rebirth, dive deeper. Hook = one physical number you can see grow ("how deep can you go?").
Read: proves the incremental genre is hot NOW -> that's Galaxy Incremental's genre. A second incremental now would split focus before Galaxy launches. Decision (Claude): put Depth's hooks into Galaxy and pull Galaxy's dates forward; a 2nd incremental only after Galaxy shows numbers.
Hooks for Galaxy: one big visible "how far" number (galaxy depth/distance), a boss guarding each sector, a collect-and-luck layer (rare shiny stars/fossil-like relics per sector), update every week.
