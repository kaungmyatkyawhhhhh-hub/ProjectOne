# SPEED ARC

A Roblox running simulator. Tagline: **"Everyone starts slow."**
Sister game of GYM ARC, built light so it runs smooth on cheap phones.

- **Prompts:** in `Prompts/` (numbered, newest last)
- **Progress notes:** in `Progress/` (Claude Code writes one per prompt)
- **Features:** in `Features/` (one note per system, Claude Code keeps them up to date)

## Rules for every session
- NEVER repeat GYM ARC's mistakes: read [[SPEED ARC - Lessons from GYM ARC]] (especially section 10) before every big prompt.
- Sound is a core feature: every action gets a designed sound before it's done.
- This folder is ONLY for SPEED ARC. Never change anything in the GYM ARC folder or the GYM ARC place.
- Light game first: follow the performance rules in the design plan.
- Kids' game: no real brands or people, no emojis in the game UI, fair monetization.
