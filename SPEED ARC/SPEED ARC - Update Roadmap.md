# SPEED ARC - Update Roadmap

Back to [[00 SPEED ARC Home|SPEED ARC Home]] · [[SPEED ARC - Game Design Document|GDD]]

## How updates work (GYM ARC lessons)
- One update every 1-2 weeks after launch: ONE headline + small fixes + 2-3 new codes.
- Title format: `[ICON UPDATE NAME] SPEED ARC` (e.g. `[⚡ STADIUM] SPEED ARC`). New game icon + Discord post + teaser image with a real in-game shot every update.
- Before adding anything: check the funnel (first race, Go Pro 1, day-1 return) and FPS; fix what dropped first.
- New content goes AFTER existing goals (never make an existing goal further away).

## Launch (v1.0) - target: milestones M1-M6 done
- Hub (League 1), City Park (L2), Big Stadium (L3), Go Pro, races (Sprint, Lap, Hurdles), shoes 1-6, coaches (8), trails (first 6), daily/quests/playtime/codes, leaderboards, profile, passes + Starter Pack, tutorial.
- Leagues 4-5 shown as "COMING SOON" gates (with a notify button).

## Update 1: MOUNTAIN TRAIL (week 1-2 after launch)
- League 4 area, Trail Run race type, Trail Grippers (shoes 7), Leaf Swirl + Ice Streak trails, a new coach pity stage. Code: MOUNTAIN.

## Update 2: WORLD GAMES (week 3-4)
- League 5 area, the Final race every 10 min, World Champion ceremony on the podium, Carbon Flyers + Golden Wings, WORLD CHAMPION title. Code: WORLDGAMES.

## Update 3: LEGEND LAPS (week 5)
- Endless rebirth with stars, Legend Track in the clouds, Legend Wall (3 statues, fixed slots), Legend shoes/trails. Code: LEGEND.

## Update 4: RELAY + CREWS (week 6-7)
- Crews (tag, crew board), Relay races (2-4 per team, baton zones), weekly crew wins. Code: RELAY.

## Seasonal (drop in when the date comes)
- **Winter Snow Dash** (December): snowy hub, sled-sprint race, snowflake trail, advent gift calendar (Dec 1-25), WINTER title.
- **New Year Fireworks Run** (Dec 31-Jan 2): fireworks finish effect.
- **Halloween Night Run** (October): foggy night hub, pumpkin trail, ghost race NPCs.
- **Summer Beach Sprint** (June-August): beach track area, sand trail, surfboard win pose.
- Event items never come back (collection value).

## Later ideas (pick by data)
- **Obstacle Run mode:** parkour-style courses (jump pads, slides, moving platforms) with leaderboards per course.
- **Marathon event:** a long race across ALL areas once a week (teleport checkpoints), huge rewards.
- **Running buddies:** small pets that run beside you (cosmetic + tiny boost), from eggs bought with coins.
- **Boost upgrades:** spend coins to upgrade boost strength/charges (a long coin sink).
- **New areas:** Desert Highway, Night City Rooftops, Beach Boardwalk, Space Track.
- **Season pass (fair):** free track for everyone + a premium track of cosmetics only.
- **Ranked races:** weekly ranked ladder with divisions (Bronze -> Diamond) and season rewards.
- **Photo mode** at the podium.

## Every update checklist
1. Headline feature built + tested (2 players if social).
2. FPS + memory check, first 15 min still smooth.
3. 2-3 codes added (DataStore, no republish needed).
4. Title + icon + Discord teaser ready.
5. Update log popup in game (what's new, short).
6. After 3 days: check the numbers, write what to fix next.
