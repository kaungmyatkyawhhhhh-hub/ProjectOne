**In one line:** the first ~10 minutes (bodies, Supernova 1, tutorial 1-7, boards, map, lighting, the v12 UI look) match the notes well. Almost everything AFTER that, and every reason to come back tomorrow, is not built.

### The 15 biggest NOT BUILT items for the player's feel
1. **No purpose / premise.** No "The galaxy went dark" line, no loading screen (ReplicatedFirst is empty), no sector names (Ember Belt...), no dark sky that lights up, no Sectors window, no GALAXY LIT %. The player has no "why". (#9, #13, #15, #20, #27, #477)
2. **Star Forge.** Only a locked anvil prop. Essence piles up with nothing to spend it on, so nothing new opens after ~10 min, exactly where the owner got bored. (#59, #60, #61, #62, #421)
3. **Ignition is only a sign.** No HUD line "IGNITION 2/4", no cinematic, no reward, no pick-1-of-2 path; it opens a bridge to an empty Sector 2. (#23, #24, #25, #17)
4. **Tutorial 2.** Still 7 one-click steps ending at Supernova 1. Planned: ~20 GOAL steps with live counters + % bar, every ~90 s, up to the Forge / Ignition. (#111, #112, #110, #122, #123)
5. **Tutorial card.** No star-spirit portrait, no Hide / Skip, no stardust payout per step; the floor beam is 3 small arrows on step 1 only. (#114, #116, #117, #119)
6. **Offline earnings + return screen.** Nothing in the code. (#411)
7. **Daily reasons to come back.** No daily streak, no daily quests, no playtime gifts. (#412, #413, #414)
8. **Weekly event + world events.** No Meteor Weekend, no cosmic weather, no Lost Stars hunt. (#415, #416)
9. **Bodies have no levels and tiers have no look.** No UPGRADE / +BODY per body; named tiers every 10 levels were CHANGED to Bronze..Cosmic at 25/50/100 owned; a body never changes look. (#82, #83, #314)
10. **"My place grows" tycoon pads.** No pads you buy and watch get built; the island only grows by itself in 6 tiers. (#388, #86, #125, #87)
11. **Second track.** No Cosmic Level XP bar and no perk grid. (#84, #85)
12. **Next-goal line and tier moments.** Under the counter only "SUPERNOVA n%"; no "NEXT: GAS GIANT - 12.4K", no "NEW: GAS GIANT!" moment (a new tier only plays a buy sound). (#223, #222)
13. **Small-reward feedback.** Income is silent (no tick, no per-second pop), x2 milestones and tree node buys have no visual, every buy has the same click. (#239, #286, #284, #242, #283)
14. **Ring 2 + automation.** No Comets / Forge / Automation branches, no capstone choice, no auto-buy; the tree stops after 4 Stellar nodes, so runs repeat. (#53, #54, #55, #56, #417)
15. **Social pull.** No friend +10% / group +10%, no server message on a Supernova, no rank aura, no server crown, no invite reward. (#394, #395, #392, #290, #403, #407)

### Also worth knowing (CHANGED / risky, not in the 15)
- **First Supernova** is still ~9-10 min for every run; the 4 Nov decision was ~5 min for run 1 only. (#77)

- **First Supernova cinematic** can't be skipped and the camera never sets Camera.Focus (Playbook rules). (#317, #316)

- **Stock Roblox sparkle texture** on every world particle, against "our own textures only". (#281)
- **Shop:** the Store (E) is open from second 1; the rule was no shop before tutorial step 7. (#448)
- **4 Nov prompts not run yet:** Purpose, Tutorial 2, Boards one job each, Why it doesn't feel like Regrowth. Their rows are NOT BUILT because they haven't been sent, not because a build failed.
